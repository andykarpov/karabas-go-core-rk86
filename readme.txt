Keys:

WIN+ESC 			-- OSD MENU
WIN+A   			-- autostart ON/OFF
WIN+V   			-- color WHITE/GREEN
WIN+M   			-- sound ON/OFF
WIN+B   			-- switch BIOS.ROM/BIOSSD.ROM
CTRl+ALT+DEL 		-- RESET
CTRl+ALT+BACKSPACE 	-- CORE LOADER

SEGA joysticks is mapped to cursor keys
A       			-- ENTER
B       			-- SPACE
R+START 			-- OSD MENU toggle
X+Z     			-- RESET
